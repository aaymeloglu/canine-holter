# DR400 Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Load a reused-card DR400/DR200 `flash.dat`, exclude the open-electrode lead-off tone, trim a long off-body tail, and report the trimmed time.

**Architecture:** The parser stops at the first ECG block whose session key (bytes 466..472) differs from the first ECG block's. The quality gate gains an absolute lead-off rule, computes its amplitude median over windows the absolute rules did not condemn, and trims a trailing off-body region; `SignalQuality.trimmed_sec` carries it to the pipeline (which slices samples before detection) and to the report's Duration row.

**Tech Stack:** Python 3.11, NumPy, pytest. Spec: `docs/superpowers/specs/2026-09-01-dr400-reused-card-and-off-body-tail-design.md`.

```python
def data_block(
    encoded: np.ndarray,
    *,
    source_position: int = 5900,
    sequence: int = 4,
    serial: int = 52837,
) -> bytes:
    """One ECG block. sequence/serial are the recording sequence number and
    recorder serial number that every block of one recording repeats."""
    assert encoded.shape == (304, 3)
    nibbles = encoded.astype(np.uint8).reshape(-1)
    packed = nibbles[0::2] | (nibbles[1::2] << 4)

    block = bytearray(512)
    struct.pack_into("<I", block, 0, 512)
    block[4] = 0x1E
    struct.pack_into("<I", block, 6, source_position)
    block[10:466] = packed.tobytes()
    struct.pack_into("<HI", block, 466, sequence, serial)
    return finish_block(block)
```

Constants: `MAX_DIFFERENCE_POWER_RATIO = 3.0  # variance of sample-to-sample differences over variance of the window: 4 for a pure alternating signal, 2 for white noise, under 1.8 for ECG at 180 Hz. The front end's AC lead-off excitation at half the sample rate when an electrode is open.`

`SignalQuality` gains `trimmed_sec: float = 0.0` with the docstring line "trimmed_sec: off-body tail dropped from the end; the recorder ran duration_sec + trimmed_sec."

```python
def _difference_power_ratio(windows: np.ndarray) -> np.ndarray:
    signal_var = windows.var(axis=1)
    diff_var = np.diff(windows, axis=1).var(axis=1)
    return np.divide(diff_var, signal_var, out=np.zeros_like(diff_var), where=signal_var > 0)
```

In `assess_quality`, after `flat`:

```python
    lead_off = _difference_power_ratio(windows) > MAX_DIFFERENCE_POWER_RATIO

    reference = ptp[~(lead_off | flat_line)]  # the absolute rules' windows would drag the median
    median = float(np.median(reference)) if reference.size else 0.0
    if median <= 0:
        return SignalQuality(duration, ((0.0, duration),))
```

Constants:

```python
LEAD_OFF_RUN_SEC = 300.0  # a lead-off run this long is the recorder off the body; shorter is a loose electrode during wear
TAIL_BRIDGE_SEC = 1800.0  # off-body runs closer than this are one tail (a package handled in transit is not a re-attachment); a tail shorter than this stays excluded time inside the duration
```

```python
def _runs(mask: np.ndarray) -> list[tuple[int, int]]:
    """(start, end) index pairs of the True runs in mask, end exclusive."""
    edges = np.flatnonzero(np.diff(np.r_[False, mask, False].astype(np.int8)))
    return list(zip(edges[0::2].tolist(), edges[1::2].tolist()))


def _tail_start(lead_off: np.ndarray) -> int:
    """First window of the off-body tail, or len(lead_off) when there is none."""
    n = lead_off.size
    min_run = LEAD_OFF_RUN_SEC / WINDOW_SEC
    bridge = TAIL_BRIDGE_SEC / WINDOW_SEC
    start = n
    for run_start, run_end in reversed(_runs(lead_off)):
        if run_end - run_start < min_run:
            continue
        if start - run_end >= bridge:
            break
        start = run_start
    return start if n - start >= bridge else n
```

In `assess_quality`: rename the first `duration` to `recorded`, then after `bad`:

```python

    duration = recorded if kept == n else kept * WINDOW_SEC
```
